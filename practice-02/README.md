Во втором эксперименте изначально использовалась функция:

```js
const square = (value) => {
  value * value;
};
```

Она возвращала:


4. Задание 2

В работе используется объект задачи следующего вида:

```js
{
  id: 20,
  title: "Подготовить демонстрацию",
  completed: false,
  priority: "medium"
}
```

Поле id должно быть положительным безопасным целым числом.

Поле title должно быть строкой длиной от 1 до 100 символов после удаления пробелов по краям.

Поле completed при создании новой задачи всегда равно false.

Поле priority может принимать значения:

```text
low
medium
high
```

По умолчанию используется:

```text
medium
```

Для создания задачи реализована функция:

```js
createTask(id, title, priority)
```

При успешном создании она возвращает объект:

```js
{
  ok: true,
  task: {
    id,
    title,
    completed: false,
    priority
  }
}
```

При некорректных данных возвращается:

```js
{
  ok: false,
  error: "Описание ошибки"
}
```

6. Задание 4

Для изменения списка были реализованы функции:

```text
addTask()
setTaskCompleted()
renameTask()
removeTask()
```

addTask добавляет новую задачу в конец нового массива.

setTaskCompleted изменяет состояние completed выбранной задачи.

renameTask изменяет название задачи.

removeTask удаляет задачу по id.

При изменении данных исходный массив не изменяется.

Для добавления используется spread:

```js
[...tasks, newTask]
```

Для изменения задачи используется map и создание нового объекта:

```js
{
  ...task,
  completed
}
```

Для удаления используется filter.
