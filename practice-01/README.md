3. Задание 1

Файл hello.js был запущен через Node.js и браузер.

При запуске через Node.js:

```text
Тип document: undefined
```

При запуске через браузер:

```text
Тип document: object
```

Разница связана с тем, что браузер предоставляет объект document для работы с HTML-страницей. В Node.js HTML-страницы нет, поэтому document отсутствует.

При запуске через Node.js результат появляется в терминале. В браузере результат выводится в Console инструментов разработчика.

7. Задание 5

В исходной программе было две ошибки.

Первая ошибка связана со сложением строк:

```js
const completedTotal = completedText + additionalText;
```

Значения `"3"` и `"2"` объединялись в строку `"32"` вместо получения числа 5.

Из-за этого результат был:

```text
Выполнено: 32
Осталось: -24
Контрольная сумма: 6
```

Для исправления строки были преобразованы в числа с помощью Number().

Вторая ошибка находилась в условии цикла:

```js
taskNumber < 4
```

Цикл выполнялся только для значений 1, 2 и 3.

Условие было изменено на:

```js
taskNumber <= 4
```

После исправления программа выводит:

```text
Выполнено: 5
Осталось: 3
Контрольная сумма: 10
```

Таблица ошибок:

| Ошибка | Что наблюдалось | Причина | Исправление | Результат |
|---|---|---|---|---|
| Количество задач | Получалось `"32"` и `-24` | Складывались строки | Использован `Number()` | Выполнено 5, осталось 3 |
| Граница цикла | Сумма была 6 | Число 4 не входило в цикл | `< 4` заменено на `<= 4` | Сумма 10 |
